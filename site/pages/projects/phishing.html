Projects / Phishing investigation

Phishing email investigation

Course exerciseEmail analysis · File reputation · Triage

A recruitment email contains a suspicious executable attachment. The exercise asks whether the alert should be escalated for further investigation.

Summary

The supplied scenario describes an employee downloading and opening bfsvc.exe. The exercise report records a known malicious file hash and an escalation to SOC Level 2.

Escalation is justified by the reported opening of the file and its malicious reputation. The email's spelling mistakes and sender inconsistencies support suspicion, but do not establish execution or compromise on their own.

Evidence and interpretation

Available informationWhat it supports

Escalation decision

The ticket is marked Medium in the supplied material. The report escalates it to Level 2 because the file was reportedly opened. A real investigation would reassess priority using endpoint evidence, affected assets and the organization's severity criteria.

A useful handover would include the original email, affected account and device, relevant timestamps with their time zone, the attachment hash, and the source of the execution claim.

Further investigation

These are proposed follow-up steps; they were not performed as part of this write-up.

  1. Obtain the original message and full headers to examine the delivery path and available authentication results.
  2. Review endpoint telemetry for the attachment, process ancestry, child processes and outbound connections.
  3. Search mail and endpoint logs for the same attachment hash and related indicators to assess scope.
  4. Assess containment with the incident owner under the applicable response procedure.

Limitations

This analysis uses the completed course ticket and the accompanying file-reputation exercise. It does not include independent malware execution, reverse engineering, a fresh VirusTotal query, or endpoint forensics.

The threat-intelligence worksheet associates the hash with Flagpro and BlackTech. That is a reported association, not an independently verified attribution of this incident to a threat actor.
