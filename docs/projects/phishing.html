Phishing email investigation

Google course exerciseEmail analysis · VirusTotal · Triage

A job application email contains bfsvc.exe. The ticket says an employee downloaded and opened it.

The alert

The exercise links the attachment to a hash reported as malicious. The ticket was escalated to SOC Level 2 because the employee reportedly opened the file.

Clues in the email and ticket

  • An executable attachment is unusual for a CV or cover letter.
  • Spelling errors and sender inconsistencies add to the suspicion.
  • The ticket reports the file being opened. Endpoint logs would be needed to confirm what ran.
  • The VirusTotal worksheet records malicious detections for the hash. That alone doesn't show the extent of any compromise.

SHA-256 from both exercise reports:

54e6ea47eb04634d3e87fd7787e2136ccfbcc80ade34f246a12cf93bab527f6b

Why escalate

The ticket is marked Medium. Reported execution of a file with a malicious reputation calls for endpoint investigation. A handover should include the email, account and device, timestamps, attachment hash and the source of the execution report.

Checks I would run next

  1. Read the original email headers and authentication results.
  2. Check endpoint logs for the process, its parent and child processes, and outbound connections.
  3. Search mail and endpoint logs for the hash to find other affected devices.
  4. Discuss containment and priority with the incident owner.

Material used

This note uses the completed course ticket and VirusTotal worksheet. The follow-up checks above weren't performed. The worksheet mentions Flagpro and BlackTech; that association hasn't been independently verified for this scenario.
