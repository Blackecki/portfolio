Cryplab

Personal learning projectPython · Hashing · AES-GCM

A Python command-line project for understanding hashing and authenticated encryption through small, working features.

Source code ↗ · Functional verification report ↗

Goal and contribution

I built Cryplab to move from reading about cryptography to using the libraries correctly. My main learning challenge was understanding the library interfaces and how to connect them to a command-line workflow. I worked through this using documentation and online resources.

The project uses Python's hashlib and the cryptography library. The encryption algorithm is provided by the library; my implementation handles the surrounding workflow, encoding, inputs and outputs.

What is implemented

  • Text hashing: UTF-8 input and a SHA-256 hexadecimal digest.
  • File hashing: binary files are read in chunks rather than loaded entirely into memory.
  • Authenticated encryption: AES-256-GCM, a generated 32-byte key and a fresh 12-byte nonce per encryption call.
  • Command-line workflow: menu actions for text hashing, file hashing and text encryption, with Base64 output and key export.

Decisions and next steps

Using a maintained cryptography library keeps algorithm implementation separate from application code. Chunked reads suit file hashing without requiring the entire file in memory. Base64 makes binary output transferable as text; it does not protect a key.

The next improvements are repeatable automated tests in the project repository, a dependency file and clearer key-handling documentation.

Run the CLI locally

From a local development environment:

git clone https://github.com/Blackecki/Cryplab.git
cd Cryplab
python -m pip install cryptography
python main.py

The recorded verification tests the library functions rather than every menu interaction.
