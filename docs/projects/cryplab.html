Cryplab

Python CLISHA-256 · AES-GCM

A command-line tool for hashing text and files, encrypting text and exporting keys.

Code on GitHub ↗ · Test results

Writing the tool

I built Cryplab to learn how to use Python's cryptography libraries. Understanding the library interfaces was the hardest part. I worked through the documentation and online examples, then connected the functions to a terminal menu.

Features

  • SHA-256 text hashing with Python's hashlib.
  • File hashing in chunks, so the whole file doesn't have to fit in memory.
  • AES-256-GCM text encryption using cryptography, a generated 32-byte key and a fresh 12-byte nonce per call.
  • Base64 output and key export through a menu.

Tests

Nine checks passed against commit b56f464:

  • SHA-256 known answers for abc and empty text, plus a file larger than the read buffer.
  • Key length, Unicode and empty-text encryption round trips, and rejection of a wrong key or modified ciphertext.
  • Base64 key export and import.

The test record lists the runtime and results. It covers the hashing and encryption functions. The full menu flow and key storage need separate testing.

Next changes

I want to add repeatable tests to the repository, a dependency file and clearer instructions for handling keys. Base64 only changes their representation; exported keys still need to be kept private.

Run locally
git clone https://github.com/Blackecki/Cryplab.git
cd Cryplab
python -m pip install cryptography
python main.py
